# Structure technique : bonbonsmonstres

Arborescence des sources principales :

- `src\App.tsx`
- `src\Sprite.tsx`
- `src\game.ts`
- `src\index.css`
- `src\main.tsx`
- `src\sound.ts`
- `src\sprites.ts`
- `src\utils\cn.ts`
- `index.html` : point d'entree SPA avec meta tags SEO complets
- `vite.config.ts` : configuration de build single-file et base URL
- `package.json` : dependances React 19, TypeScript, Tailwind 4
