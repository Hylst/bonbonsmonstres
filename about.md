# A propos de Bonbons Monstres : Chaud Devant

**Bonbons Monstres : Chaud Devant** est un gestion / tycoon arcade developpe par **Geoffroy Streit** (alias **Hylst**).

## Le jeu
Gère une confiserie nocturne pour monstres voraces : prépare les yeux gélatineux, chauffe les chaudrons, encaisse les pièces d'or et améliore ton étal avant le rush de minuit.

## Le createur
- Developpeur d'applications, ancien graphiste et compositeur
- Adepte de retrocomputing et de demoscene
- Createur de la plateforme de jeux 100% front-end Hylst.Games

## Stack technique
- React 19 + TypeScript + Tailwind CSS 4
- Vite 7 + vite-plugin-singlefile
- 100% statique, sans serveur ni collecte de donnees
